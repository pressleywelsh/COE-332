This repository holds all the files needed for homework 1. 
It contains ml_json_reader.py which reads the data from Meteorite_Landings_Simple.json and summarizes it by checking the hemisphere and computing the average mass. 
It contains ml_json_converter.py which takes the data from Meteorite_Landings_Simple.json and turns it into a pydantic model and puts it into a csv, xml, and yaml.
These scripts contain a path to Meteorite_Landings_Simple.json which contains data about meteorite landings. It is in the root repository.
