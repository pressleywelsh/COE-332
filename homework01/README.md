This repository holds all the files needed for homework 1. 
It contains ml_json_reader.py which reads the data from Meteorite_Landings_Simple.json and summarizes it.
It contains ml_json_converter.py which takes the data from Meteorite_Landings_Simple.json and puts it into a csv, xml, and yaml.
It also contains Meteorite_Landings_Simple.json which contains data about meteorite landings.
